# Aqyl Hub — демо-сайт

Концепт сайта для центра дошкольного развития и продленки Aqyl Hub (Астана, Instagram @aqyl.hub.kz).
Чистые HTML, CSS и JS, без сборки и внешних зависимостей.

## Файлы
- `index.html` — главная: первый экран, программы, преимущества, подбор программы, мини-игра, отзывы, акции
- `programs.html` — дошкольная подготовка, продленка (пакеты VIP и Стандарт), занятия
- `center.html` — о центре: школы рядом, условия, отзывы, аренда кабинетов
- `contacts.html` — адрес, часы, WhatsApp, Instagram, 2ГИС, форма записи (открывает WhatsApp)
- `css/style.css` — оформление и анимации
- `js/main.js` — язык RU/KZ, меню, подбор программы, мини-игра, анимации
- `assets/img` — логотип и фото, `assets/fonts` — шрифт Nunito

## Как править
- Русские тексты страниц лежат в HTML, казахские — в списке `KZ` в начале `js/main.js` (ключ совпадает с `data-i18n`).
- Тексты подбора программы, мини-игры и сообщений WhatsApp — в списке `T` там же, на двух языках.
- Номер WhatsApp для готовых сообщений задан в `js/main.js` в строке `const WA`.

## Откуда данные
Все из Instagram @aqyl.hub.kz (шапка профиля, посты, актуальное): адрес, часы 09:00–18:00, телефон, цена дошкольной подготовки 48 000 тенге, состав пакетов, акции, школы рядом, отзывы.
Цены пакетов продленки на сайте нет: в актуальном указано 95 000 тенге, но это афиша времен открытия, до появления пакетов VIP и Стандарт.
